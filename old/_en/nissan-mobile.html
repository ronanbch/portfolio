Nissan mobile Guidelines

Brief.

Le site Nissan utilisant le CMS Adobe Experience Manager, l’objectif du projet était de référencer tous les composants mobile friendly utilisables sur le site et d’écrire les règles d’utilisation de chaque composants.

Rôle.

UX designer produit

Contexte.

UX designer pour le compte de Nissan à l’agence Publicis Sapient

Quand.

Octobre 2019 - Janvier 2020

Solution.

Création d’un fichier répertoire des différents composants disponibles sur le site Nissan avec organisation de ces derniers en 3 catégories : Optimisés, Restreints, Interdits.
- Utilisation d’AEM (CMS Nissan) afin de définir les règles d’utilisation de chaque composant
- Écriture de documents de guidelines afin d’optimiser l’utilisation des composants répertoriés pour leur usage mobile
- Mise à jour du design system original de Nissan
- Création de deux nouveaux fichiers de design system (desktop et mobile) répertoriant les composants utilisables (et leurs variations) organisés de la même manière que dans les guidelines
